# PlanDeck 0.1.2 Beta

PlanDeck 0.1.2 moves subscription credentials out of the public Catalog and introduces environment-backed account Groups for supported AI Tools.

## Highlights

- Keep subscription credentials in `~/.config/ai-subscriptions/subscriptions.env`; the frontend receives only credential presence and fingerprints.
- Group multiple subscription accounts under one fixed provider, base URL, and model contract.
- Bind Codex, opencode, Claude Code, and Hermes using stable environment-variable references.
- Switch the selected account inside a Group without rewriting Tool configuration.
- Synchronize bound Tool configuration, with automatic backups, when a Group contract changes.
- Show and persist whether a Tool needs a reload or restart, with an explicit recheck action.

## Migration and security

- Use **迁移旧凭据** to move supported legacy Catalog and shell credentials into the environment file.
- Migration validates the generated environment with `/bin/zsh`, backs up every affected file, and rolls back the complete operation on failure.
- Use **配置环境变量** to install the independent shell loader and `ai-env-run` wrapper. PlanDeck does not use `launchctl setenv`.
- Public Plan objects and `catalog.json` no longer persist API keys.

## Compatibility

- Codex, opencode, Claude Code, and Hermes support environment Group binding.
- OpenClaw preserves its existing auth profile and does not yet bind environment credentials.
- Kimi Code and ZCode remain detectable, but environment binding and managed switching are disabled until their credential contracts are verified.
- Running Tools are not restarted automatically after an account or Group change.

## Current limitations

- Apple Silicon macOS only.
- This build remains unsigned and is not notarized with Apple Developer ID.
- macOS may display an unidentified developer or Gatekeeper warning on first launch.
- PlanDeck reads and updates local AI Tool configuration files; review generated diffs and backups before confirming changes.
- Verify the downloaded DMG with `SHA256SUMS` before opening it.
