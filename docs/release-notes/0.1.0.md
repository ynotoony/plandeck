# PlanDeck 0.1.0 Beta

- Apple Silicon macOS only.
- This build is unsigned and not notarized.
- macOS may display an unidentified developer or Gatekeeper warning.
- PlanDeck reads and updates local AI Tool configuration files. Backups are created before writes.
- Verify the downloaded DMG with `SHA256SUMS` before opening it.
