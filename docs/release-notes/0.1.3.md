# PlanDeck 0.1.3 Beta

PlanDeck 0.1.3 fixes missing child items in the macOS status-bar menu.

## Highlights

- Plan 清单改为可搜索、可筛选的高密度列表，右侧详情栏支持显式保存、凭证状态查看和安全删除保护。
- 正在被任意 Tool 使用的 Plan（包括隐藏 Tool）不可删除；凭证明文不出现在清单表格中。
- Hide or restore Tools without deleting configuration; the preference persists locally and applies to the window and status-bar menu.
- Skip empty, unconfigured Tools in the cascade view by default.
- Plan and Model children remain visible for Tools that are not yet bound to an environment Group.
- Unavailable Model actions are disabled while their Plan parent remains expandable.
- Bound Tools continue to show only the Group's member Plans and fixed model.

## Compatibility

- Apple Silicon macOS only.
- This build remains unsigned and is not notarized with Apple Developer ID.
