# PlanDeck 0.1.1 Beta

PlanDeck 0.1.1 is the first update after the initial public Beta. It expands Tool compatibility, adds Plan availability checks, and introduces signed in-app updates for future releases.

## Highlights

- Add ZCode and Kimi Code configuration recognition and Plan/model switching.
- Test a Plan's endpoint, credential, and model availability from the Plan catalog.
- Review recent GitHub Release notes and install signature-verified updates in the app.
- Optionally check for updates at startup and persist the preference.
- Preserve existing provider credentials when a selected Plan does not supply a replacement.

## Fixes and compatibility

- Fix light-theme root background consistency.
- Improve SHA-256 credential fingerprint compatibility.
- Update the coupled Vite and Svelte plugin toolchain.
- Add reproducible requirement intake, sizing, release planning, and verification records.

## Upgrade notes

- Existing 0.1.0 installations may need to download and install 0.1.1 manually. Future releases can use the in-app updater.
- PlanDeck creates backups before writing supported Tool configuration files. Review the generated diff before confirming a switch.

## Current limitations

- Apple Silicon macOS only.
- This build remains unsigned and is not notarized with Apple Developer ID.
- macOS may display an unidentified developer or Gatekeeper warning on first launch.
- PlanDeck reads and updates local AI Tool configuration files.
- Verify the downloaded DMG with `SHA256SUMS` before opening it.
